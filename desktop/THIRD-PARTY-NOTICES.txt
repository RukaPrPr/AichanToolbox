艾酱图片工具箱 8.0.2 — 第三方组件说明

1. NetVips 3.2.0
   .NET bindings for libvips，MIT License。
   https://github.com/kleisauke/net-vips

2. libvips 8.18.5 Windows x64 native package
   LGPL-3.0-or-later。完整依赖清单随程序置于：
   tools\libvips-THIRD-PARTY-NOTICES.md
   https://github.com/libvips/libvips

3. Jpegli / cjpegli（libjxl 0.11.2 官方 Windows 构建）
   随附许可文件置于：tools\jpegli-licenses\
   https://github.com/google/jpegli
   https://github.com/libjxl/libjxl

4. FFmpeg
   可选兼容组件，仅用于 libvips 无法读取的少数格式兼容回退；默认主程序包不包含该文件。
   https://ffmpeg.org/

5. Microsoft Edge WebView2 Runtime / WebView2 SDK
   用于 WPF 桌面界面承载。
   https://developer.microsoft.com/microsoft-edge/webview2/

6. SharpCompress 0.50.1
   用于 ZIP 读取、密码与文件名编码兼容，MIT License。
   完整许可文件置于：tools\SharpCompress-LICENSE.txt
   https://github.com/adamhathcock/sharpcompress
