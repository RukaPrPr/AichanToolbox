艾酱图片工具箱 8.0.1（WPF 工作流版）

启动：双击 AichanToolbox.exe。请先完整解压 ZIP，不要直接在压缩包中启动，也不要单独移动 EXE。

基本操作：
1. 在“导入 / 文件列表”节点选择图片，PNG、JPG/JPEG、WebP 等格式都会保留在列表中。
2. 从节点右侧彩色圆点拖到下一节点左侧圆点，即可建立连接。
3. 拖动空白区域平移画布，滚轮围绕指针缩放；“适应”可显示全部节点。
4. 格式筛选节点提供 PNG、JPG、WebP、其他四个独立出口。
5. 大小筛选可检查原始文件或当前工作流结果；分辨率筛选支持宽、高及 AND/OR 条件。
6. JPG 画质默认 100%，缩放范围为 20%—100%。JPEG 使用 Jpegli 高画质 4:4:4 编码；单次 JPG 输出采用分块流式像素传输，不再生成中间 PNG 文件。
7. “精确预估”会真正执行工作流并缓存中间结果；正式运行时可直接复用缓存。
8. 顶部配置下拉框可直接选择内置工作流；“保存”覆盖当前配置，“＋”另存新配置，“✎”改名，“×”删除当前配置。配置自动保存在本机应用数据目录。
9. 顶部配置与并行数量使用内置毛玻璃菜单；重置缩放会保持当前画布中心，选中节点会优先显示在最上层。
10. 节点下拉箭头会随画布一起缩放；DOM 节点与 WebGL 连接层共用同一世界坐标，画布缩放不会改变连线曲率。
11. 节点与顶部下拉框使用等宽、居中的毛玻璃菜单；节点图标采用语义化矢量图标，窗口内容贴合圆角外壳且不再保留黑色内框。
12. 软件窗口由 Windows 原生 DWM 裁剪圆角，四角不再露出 WPF / WebView2 的矩形黑色背景。
13. 默认界面采用银白玻璃主题：珍珠白画布、半透明灰色工具栏与侧栏、白色玻璃节点，并保留低辉光彩色工作流连接线。
14. 节点恢复半透明玻璃层；数字输入控件固定使用浅色系统外观；主按钮悬停保持清晰紫色；节点端口外环与中心颜色一致。
15. 使用“替换原文件”运行后再次预估或运行时，会提示原图片已删除，并询问是否以上次生成的新图片继续处理；选择“否”不会启动任务。
16. 在上述提示中选择“是”后，文件列表会把新图片的格式、大小和分辨率采纳为新的原始基线；最大化窗口会避开 Windows 任务栏，数字微调箭头采用上下对称的自绘样式。
17. “解压 ZIP”位于预处理分类，可批量导入 ZIP，并分别解压到源 ZIP 同目录的同名文件夹；已有同名目录时会使用“(2)”“(3)”等新目录，绝不覆盖旧内容。
18. 精确预估不估算 ZIP 解压阶段：尚未解压时会提示先执行预处理；直接运行工作流则会自动解压并继续处理图片。
19. “打包 ZIP”位于后处理分类，固定使用 Store/仅存储，可保留非图片文件；不显示最终 ZIP 大小预估。启用“替换原 ZIP”时，仅在新 ZIP 完整写入并通过读取校验后替换源包。
20. ZIP 密码只在当前运行期间保存在内存中，不写入工作流配置文件。解压会拒绝越界路径，并限制异常数量及异常膨胀体积。
21. “删除解压目录”位于后处理分类，连接在 ZIP 压缩节点之后；只有新 ZIP 成功生成并通过完整读取校验时，才会永久删除对应解压文件夹及其内容。
22. 清理节点只能删除当前解压节点创建并登记的目录；未登记目录、图片处理失败或 ZIP 打包失败时均拒绝删除。清理操作不进入回收站，运行前会再次确认。
23. 清空图片、清空 ZIP、清空工作流、删除配置、替换文件及预处理等全部业务确认统一使用软件内毛玻璃对话框；只有 Windows 文件/目录选择器与 WebView2 无法启动时的应急提示保留系统界面。
24. 原 ZIP 被工作流替换后，再次预估或运行会询问是否使用新 ZIP；确认后会将新 ZIP 采纳为输入基线，清除旧图片任务与预估缓存，再重新解压，避免复用已删除图片的状态。
25. “目标体积压缩”节点使用 Jpegli 从同一工作底图进行最多 5 次真实编码，自动寻找不超过目标体积的最高已验证画质；默认起始画质 90%、画质上限 95%、画质下限 50%。达标与未达标图片分别从两个出口继续处理。
26. 目标体积预测采用单图对数拟合与同节点批次画质提示。每个候选都必须真实编码验证，不会把 70% 的结果再压成 60%；“未达标时输出最小结果”默认关闭，关闭时丢弃尝试并把入口状态原样传给未达标出口，开启时传递体积最小的 JPG。
27. 顶部“黑白优化”默认开启，只对 RGB 通道差异极小的明确黑白图启用单通道 JPG 编码；泛黄扫描、低饱和彩页和明确彩色内容保持原色。
28. “逆网点化”节点位于图片处理分类，提供轻微、中度、强力三档横向滑块，默认中度；处理会灰度化并平滑规则网点。
29. “JPG 画质”已更名为“JPG 画质压缩”；目标体积压缩的达标出口与开启“输出最小结果”后的未达标出口会输出 JPG。窗口支持从四边和四角拖动调整大小。
30. 7.6 起桌面宿主使用标准 WebView2，工作流连接线改由固定视口 WebGL 图层绘制；拖动和平移期间始终保留节点毛玻璃与完整连线光晕。连接线跨越垂直位置时使用连续控制点公式，不再切换路径形状。
31. 画布空白区域与节点标题栏使用同一套无星星的 28×28px 艾酱透明光标；拖动中即使经过其他节点或控件也保持一致。

缓存位置：
处理缓存保存在软件目录下的 Cache 文件夹。正常关闭会自动删除本次会话缓存；异常退出遗留的旧会话会在下次启动时自动清理。软件目录必须具备写入权限。

文件替换：
替换原文件时会等待短暂的资源管理器预览占用，并串行执行回收站操作。libvips 不保留源文件操作缓存，以避免精确预估后仍占用原图。

替换原文件：
启用“替换原文件”后，运行前会再次确认。处理成功时原文件进入回收站；JPG 压缩保持原文件名。建议首次使用时先关闭此选项验证结果。

并行处理：
可选择 1—16 路，默认 6 路，适合 Ryzen 7 9800X3D。图片解码、色彩与缩放由 libvips 执行，JPEG 由 Jpegli 编码。工作流采用延迟编码，尽量只从原图生成一次最终 JPEG；显卡计算暂未启用。

运行组件：
便携版发布目录已包含 .NET 10 桌面运行时、libvips 与 Jpegli；精简版需要系统预先安装 .NET 10 Desktop Runtime。界面需要 Microsoft Edge WebView2 Runtime，Windows 10/11 通常已自带；若被精简，软件会显示缺少组件的提示。第三方组件许可文件随程序一同分发。

FFmpeg 兼容组件：
主程序默认不再携带体积较大的 FFmpeg。PNG、JPG、WebP、AVIF、HEIC 等常用格式优先由 libvips 解码；只有 libvips 无法读取的少数文件才需要把与本版本配套的 ffmpeg.exe 放入 tools 文件夹。缺失时软件会给出明确提示，不影响其他图片处理。
